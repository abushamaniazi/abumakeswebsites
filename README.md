# ABU.DEV

Interactive portfolio and web template agency site built with vanilla HTML, CSS, and JavaScript.

## Features

* **Themes:** Light and dark mode support with preference persistence.
* **Interactive Spotlight Cursor:** Inverted cursor spotlight effects with mobile touch support.
* **BG Particle Effect:** Magnetic background boids-like particles.
* **Text Animations:** Odometer text scramble effects.
* **Website Embed:** Preview iframe embed for demo templates.
